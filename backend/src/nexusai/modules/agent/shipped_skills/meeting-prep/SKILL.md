# Meeting prep

1. Find out who and what: the people, the topic, and when. Ask once if it isn't clear.
2. Search mail for the topic and for each person's recent threads with the person. Read the latest of each, not everything.
3. Search documents for the topic's name and any project names that came up.
4. Write one short page:
   - **Why it's happening**, in a sentence.
   - **Where things stand**: what was agreed, what's open, with citations.
   - **What they'll likely ask**, and the person's best answer from what you found.
   - **What the person owes**, and what's owed to them, with dates.
   - **Questions to raise**, at most three.
5. Cite every fact. If something matters and you couldn't find it, say so rather than guessing.
