# My mail categories

Use the existing categories and their settings. Exact folders use their literal sender/subject-prefix rules. Smart folders use their descriptions and can overlap when both genuinely fit.

Team work, customer conversations and regular reports are themes to recognize, not instructions to invent folders. If no existing Smart folder fits, leave the message unfiled and suggest a new folder for me to accept. Track actions through status and proposed work rather than creating an Action folder for every obligation.

PLM and Swarm default to Exact matching with Priority off. Do not change their mode or Priority setting without my instruction.
